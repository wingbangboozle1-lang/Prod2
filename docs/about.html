About this site and how it is checked

Who writes it

The Editorial team. No named author has been supplied (FR-11). The brand name is a working name (FR-12).

Affiliate relationship

As an Amazon Associate I earn from qualifying purchases. This site is not endorsed by or affiliated with Amazon. Product links go to Amazon and carry the Associates tracking tag. They are marked sponsored.

How a product row is checked

  1. The supplied short link is followed to the Amazon product page it redirects to. That ASIN is recorded as the observed redirect target.
  2. The intended ASIN is recorded separately and left unverified until the owner confirms it.
  3. Spec values are quoted from the listing title, marked “as listed”. Prices, ratings and commission rates are left blank.
  4. Every row carries a link to its official source. The verify script checks this on each build.

Reader data

The site sets no cookies and loads no third-party analytics or tracking script. Outbound clicks are counted only in the page’s own memory and sent nowhere until an endpoint is chosen (FR-09). Our hosting provider, GitHub Pages, keeps its own standard server logs, which we do not control.
