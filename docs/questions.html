Open questions

What we cannot answer yet, and who can.

Fifteen questions stand between this site and a decision that is not a guess. Each one names what is missing, how to find it out, and what it blocks. None of them can be answered by reading the site harder — that is the point of listing them.

Why this page is public

A register of unknowns is more useful than a confident page built on assumptions. Three of these are owner actions — no amount of agent work closes them: Associates enrollment (Q-01), Search Console verification (Q-P08) and domain control (Q-P06). Nine are answerable from a source we can reach. Three need a decision rather than a source.

How we would find each answer

These are the discovery methods, ordered by how cheap they are to run. Each one names the questions it can close.

MethodWhat it involvesClosesCost
Read the official page again, on a dated pass Re-fetch the listing or policy page and record the value with the date and the exact sentence it came from. This is how every published figure here was obtained. Q-27, Q-31, Q-P03 Minutes. Free.
Log in to Associates Central Confirm the Partner Tag, generate or validate one Special Link per product, run a single test click, and read it back in the tracking report. The protocol is on the measurement page. Q-01, Q-P01 One owner session.

Run a small controlled test Change one thing, hold everything else, and compare over a defined window. For links: one product, one link, one report. For topics: fourteen days of search data before changing the calendar. Q-P02, Q-P04, Q-P07 One to two weeks of elapsed time.
Ask a lawyer or a trademark search Name clearance is a legal question. It is not answerable by checking whether a domain is free, and it is not something this project should guess at. Q-19 Owner decision, possibly paid.
Read the licence before using the asset Product imagery and ratings are licensed through the Associates Program, not public. Reading the IP licence tells us what is permitted before a single image is used. Q-P05, Q-27 One reading pass.
Ask the reader The question-capture form exists but ships disconnected until a consent basis is settled (Q-47). It is the only route to knowing what readers actually want answered. Q-47, then Q-P02 Blocked on a privacy decision.

Four things we deliberately did not do

  • We did not guess prices. Amazon permits published prices only when Amazon serves them or they arrive through the licensed APIs (S-POL, read 2026-11-20). A scraped figure is neither, so no price appears on this site.
  • We did not publish ratings. Same restriction, same silence. The blank is the honest answer (F-02).
  • We did not call the supplied short links invalid. Their exact status under the Participation Requirements is unresolved, not disproven (F-03). The site uses tagged links built from the verified ASINs instead.
  • We did not claim a result. Every conversion figure on this site is zero because the ledger starts empty and only accepts rows from an authorized report (Measurement).

Q-P40 Is there an official, quotable source for how these specific machines behave — holding temperature, reheat settings, preheat, clearance — or does the site stop at the specification sheet?
