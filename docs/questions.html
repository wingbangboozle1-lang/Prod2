Open questions and missing information

What we know, what we don't, and how to find out. Each card names what is missing and who can answer it — because decisions made without these answers are guesses.

Why this page exists

The brief asks for a clear list of the questions, information and answers that must be addressed before decisions can reasonably be made — and for suggestions that discover the missing information. This register is that list; the suggestion queue proposes the paths, and the decision log records what was chosen.

Q-01 Is the Associates account enrolled under tracking ID shopnow047c-20, and has each published link been validated in that account?

What we know
The owner supplied shopnow047c-20 (brief, 2026-11-19). The format matches the documented US Store ID pattern (S-TAG). All five supplied short links resolved without a tag= (F-03). The site now publishes tagged Special Links built from verified ASINs. Whether the ID is registered and active is not observable from outside Associates Central.
What is missing
Account enrollment status; Partner Tag registration; whether test clicks report.
How to discover it
Owner logs into Associates Central: confirm the Partner Tag, generate or validate one Special Link per product, run a test click and read it in the report (protocol on the measurement page).
Answerable by
The account holder.

Q-19 Is the site's own trade name cleared, and does it contain an Amazon Mark?

What we know
No Amazon Mark appears in any page title, meta description or target keyword (tools/checks.py fails the build if one does). The current wordmark is the project's established name 'Prod2' (D-P03), served under a github.io subpath — the site has no domain of its own yet.
What is missing
Whether a consumer-facing name (candidates in SG-01) collides with an existing trademark.
How to discover it
Re-read the Trademark Guidelines (S-POL) for domain and site names; run any candidate name through a trademark search before registering a domain.
Answerable by
The owner, with a trademark search.

Q-23 Where can the self-hosted analytics endpoint run?

What we know
analytics-endpoint/server.py is standard-library Python, counts events only (no IPs, no cookies, no referrers), and is ready to deploy. GitHub Pages cannot host it. Until a host exists, settings.analytics_endpoint stays empty and the site sends nothing.
What is missing
Which host the owner wants (any VM/container/Function that speaks HTTPS).
How to discover it
Owner picks a host; run the server; set the endpoint in data/p2/settings.json; rebuild. See the measurement page for the event contract.
Answerable by
The owner.
Blocks
Shared click/conversion data, SG-06
