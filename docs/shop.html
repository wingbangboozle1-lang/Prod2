Before you click Buy

Four things to check on the listing

  • The seller and condition. The default offer on a listing can be a used unit (F-49) — check it is sold as new.
  • The size variant. Two of these are size-variant families, so confirm the option selected matches the capacity quoted here (F-08, F-P05).
  • The price. We do not publish prices because they move; the listing is the only current source (F-02).
  • Stock and delivery date. Seasonal demand changes both, and neither is something we can state from a dated read.
