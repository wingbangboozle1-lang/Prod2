Decisions

Pick a path before we build it.

Everything proposed for this site lands here first, with its evidence, its cost and what it blocks. Nothing below is implemented until a path is chosen — so this page is a review surface, not a changelog.

Before any of this: eleven facts are missing

The board below proposes work. A handful of those proposals cannot be judged until four facts exist that only the owner can obtain — whether the tracking tag is live, where analytics runs, whether a domain is controlled, and whether the brand name is clear. Those are set out, one row each, with what we know, what is missing and how it gets found, on Before you decide anything. Read that page first if you only have ten minutes; read this one when you want to pick a path.

Three paths, one choice

The thirty-four items in the queue group into three coherent strategies. They are not mutually exclusive, but they compete for the same hours, so picking one first is what actually unblocks work. Everything in a path keeps the non-negotiables: disclosure above the fold, no invented values, sponsored links marked, imagery drawn rather than copied.

Our recommendation · start here

Path A — Prove the traffic first

Ship nothing new to readers until we can see what readers do. This is the shortest route to a decision the owner can make on evidence rather than instinct.

  • SG-06 — deploy the analytics endpoint
  • SG-29 — verify Search Console, submit the sitemap
  • SG-34 — choose topics from measured queries
  • SG-14 — hold all paid promotion until one clean attribution test exists

Cost: one owner action (Search Console) plus endpoint hosting. Unlocks: every later decision becomes measurable. Blocks on: Q-01, Q-23, Q-P08.

Alternative

Path B — Consolidate the shop

Turn five products and ten guides into one dense, linkable cluster: one buyer section per product, one hub per format, and the counter-depth spec as the signature comparison.

  • SG-12 — a buyer-first section for every product
  • SG-13 — one cluster per format, linked into a hub
  • SG-02 — publish counter depth as the lead spec
  • SG-17 — seasonal merchandising tied to the calendar

Cost: editorial hours, no owner action. Risk: without Path A we cannot tell whether it worked. Best when: the site is staying at five products.

Hold · one step already taken

Path C — Rebrand and expand

Clear a consumer-facing name, buy a domain, and grow past five products. Highest ceiling, highest cost, and it cannot start until two answers arrive. 2026-11-20 update: the working brand "The Crisp Counter" already ships (SG-38, decision D-P18) on the owner's standing anti-slop directive — what still holds is the formal clearance and everything that follows from it.

  • SG-01 — ratify the working brand and run formal clearance
  • SG-33 — design-token layer so the rename is reversible
  • SG-10 — a second format page
  • SG-07 — a real "what it is like to live with" layer, once real use exists

Cost: trademark clearance, domain, and a full rename pass. Blocks on: Q-19 (clearance) and Q-P06 (domain control). Do not start: before Path A has 14 days of data.

The shortest credible path — who decides what, by when

The smallest sequence of decisions that unblocks the most work (SG-32 makes this standing; updated 2026-11-20 — the visual direction is kept, the typography ships and the working brand is adopted, so measurement now leads):

  1. SG-06 + SG-44 — verify Search Console (Q-P08, owner: paste the HTML-tag token into settings and rebuild) and host the analytics endpoint (Q-23). Decide-by: before the next cadence cycle — nothing measures until this lands.
  2. SG-38 / Q-P10 — ratify the working brand and run the formal clearance search (owner, with counsel). Decide-by: before any domain purchase or social/print use of the name.
  3. Q-47 — settle the consent basis for reader capture (owner); opens SG-36 + SG-04.
  4. SG-34 — once 14 days of measured data exist, switch topic selection to measured queries (agent, monthly review). This is Path A's payoff step.
  5. SG-39 — amend the brief's imagery line and extend the drawn-art set per season (owner + designer) once this pass has settled (Q-P05).

How to run the walkthrough

Four steps, about a quarter of an hour: (1) read the three cards above and name the path. (2) open the decision rows in that path and strike anything you disagree with. (3) for each surviving row, answer the question it blocks on from the open questions register — those are the only answers that actually change the outcome. (4) record the choice against the item's ID; the decision log takes it from there with a date. Anything you do not touch stays proposed and is not built.
