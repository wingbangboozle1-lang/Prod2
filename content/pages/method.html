The work behind it

Method and source register

How every figure on this site is checked — and the complete register of the official pages it was checked against.

The rule

A value is published only if it was read from an official source — an Amazon product listing, an Amazon policy page, a regulator's guidance, or a search engine's own documentation — and the read is dated. If a value can't be confirmed, the cell stays blank and the item goes to the Flagged for Review page. Nothing is inferred, rounded, averaged, or copied from third-party sites.

How a figure gets published

  1. Read the official page. Listing title, Item details, spec tables, bullets — recorded verbatim where wording matters.
  2. Date the read and cite the source. Each register row carries source ID + read date (below and in data/p2/products.json).
  3. Keep observations separate from intent. What a short link was observed to redirect to is stored apart from what the site intends to link (see the intent record).
  4. Re-check on later passes; never overwrite history. When a listing title drifts (as P2's has), the current string ships with its date and prior strings stay in the register (F-44).
  5. The gate. tools/checks.py fails the build on missing sources, missing disclosures, untagged product links, duplicate titles, or broken links.

What "verified" does not mean here

  • It does not mean hands-on tested — nobody has cooked with these machines (D-06).
  • It does not mean the tracking ID attributes — that lives inside Associates Central (F-57).
  • It does not mean manufacturer claims are endorsed — "±0.5°F", "1000°F safe", "NIST-certified" are recorded as the listing's own statements.

Automated checks

The published gate runs from a clean checkout: python3 tools/build.py && python3 tools/checks.py. It verifies page uniqueness (titles/meta), disclosure presence on every page, rel="sponsored" + tag on every product link, per-row source links in product tables, sitemap/feed/robots integrity, internal link integrity, and the banned-words rule for popularity claims (D-19). See ENGINE.md in the repository for the exact list.
