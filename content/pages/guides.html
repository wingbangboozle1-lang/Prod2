How these get written

One guide goes out on a set cadence, and each one is added to the sitemap and the feed in the same build as its source data — the method page explains the checks that make that automatic. Topics are chosen from the buyer questions the register can actually answer; when search-query data exists it will reorder the queue (measurement).
