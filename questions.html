Open questions and missing information

What we know, what we don't, and how to find out. Each card names what is missing and who can answer it — because decisions made without these answers are guesses.

Why this page exists

The brief asks for a clear list of the questions, information and answers that must be addressed before decisions can reasonably be made — and for suggestions that discover the missing information. This register is that list; the suggestion queue proposes the paths, and the decision log records what was chosen.

What must be answered before a decision is reasonable

Three questions set the ceiling for everything else. Until they are answered, the site can improve how it reads, but it cannot become a shop that shows prices, shows ratings, or claims testing. Each is one decision, not a project.

Question Q-P10 · commercial model

Prices, ratings and photographs — or none?

Program Policies allow prices and star ratings only through Amazon's own serving or the Creators/PA API (S-POL). The API route is the only one of the three that permits all three. SG-38

Question Q-P11 · findability

Which queries do we actually appear for?

Nothing is measured yet: Search Console is unverified and the ledger is empty by rule. Until the token is pasted in, topic choice stays editorial. SG-06

Decision D-06 · method

Will this ever be a tested publication?

The site says plainly that it has not handled these machines. Buying and testing the five would be the largest honest upgrade available. SG-41

Q-P08 Who verifies the site in Google Search Console, and when?

What we know
The site ships with everything Search Console needs to index it well: one canonical URL per page, unique titles and meta descriptions, sitemap.xml, robots.txt with the Sitemap line, and an RSS feed. The build is ready for the verification token (settings.json -> search_console.verification_token).
What is missing
Which verification method the owner prefers (HTML tag, HTML file, or DNS), and when the property will be claimed.
How to discover it
Owner opens Search Console, adds the property https://wingbangboozle1-lang.github.io/Prod2/, chooses the HTML-tag method, pastes the token into settings.json and rebuilds (or uploads the HTML file). Then submits sitemap.xml and feed.xml. Step list is on the measurement page.
Answerable by
The account holder (needs the owner's Google account).
