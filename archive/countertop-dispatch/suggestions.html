Suggestions & decisions

For review — nothing implemented

Each suggestion states what exists today, the options, what is missing, and what we would do. Nothing on this page has been built; the point is to let a reviewer pick a path first. Suggestion IDs are referenced from Flagged for Review.

S-01 · Confirm the intended products for all five submitted links

Blocked on owner

What exists: All five submitted short links were fetched live on 19 Nov 2026 and each resolved to a real, in-stock listing. The intended ASIN field in product-intent.json is null for all five, because the submitted tokens are 9 characters while official Amazon documentation defines ASINs as 10 characters (FLG-P01).

  • Option A — Owner confirms the resolved listings are the intended products → we populate intended.* with the confirmation date and source, keeping observed.* separate.
  • Option B — Owner supplies the correct 10-character ASINs → we re-resolve and re-verify against those.
  • Option C — Leave as-is → site keeps publishing observed-only records with the mismatch flagged.

Missing: a statement from the owner. This session cannot infer intent — the fields stay null until then.

Recommendation: Option A is likely sufficient (all five destinations are coherent product pages), but only the owner can say so. Takes one reply; unblocks FLG-P01.

S-02 · Decide how prices and ratings may be shown

Decision needed

What exists: Price and rating columns on the product table are withheld and flagged (FLG-P04, FLG-P05) because Amazon's Program Policies restrict displaying them unless obtained through the Creators API / PA API (with the required date/time stamp and disclaimer) or served by Amazon's own link. Observed values from our checks are deliberately not published anywhere on this site.

  • Option A — Keep withholding: listing links always show the live price. Zero compliance surface, less on-page information.
  • Option B — Apply for PA API / Creators API access → display prices with the mandated timestamp and disclaimer text, refreshed by script.
  • Option C — Use Amazon's own price widgets where available (served by Amazon → permitted under the "we serve the link" path).

Missing: the owner's Associates account status, whether API access is applied for, and the legal wording review for Option B's disclaimer.

Recommendation: Option A until API access exists; it is already what the site does. Option C is the cheapest upgrade if widgets fit the design.

Blocked on owner / Amazon

Separately, every product link on this site is already a standard Special Link with ?tag=shopnow047c-20 and rel="sponsored", all five tested live 19 Nov 2026.

  • Option A — Test one submitted link inside the enrolled Associates workflow (owner sign-in), confirm click tracking, then decide.
  • Option B — Use only self-generated Special Links on-site (current state) and keep submitted links as provenance records only.
  • Option C — Ask Associates support directly about the link.amazon format.

Missing: Associates-account click report for one tagged test click — requires the owner's sign-in; not available to this session.

Recommendation: Option B is already in force and sufficient to publish; do Option A when the owner next signs in to Associates Central.

S-04 · Provision the analytics endpoint

Ready to build

What exists: The five-event counter (events.json) ships in assets/analytics.js with no cookies and no IP collection. ENDPOINT is empty, so events currently stay in the browser. The endpoint contract is written down in tools/analytics-endpoint.md.

  • Option A — Cloudflare Worker + KV: ~30 lines, no server to run, free tier generous.
  • Option B — Small self-hosted Flask/Node app behind your domain: full control of the ledger append.
  • Option C — Leave local-only: zero data, zero infrastructure; the counter still works per-browser for demos.

Missing: owner preference for hosting, and a domain to receive events (GitHub Pages itself cannot host the endpoint).

Recommendation: Option A when the site has readers; Option C until then. Either way the code path is already written and gated behind one constant.
