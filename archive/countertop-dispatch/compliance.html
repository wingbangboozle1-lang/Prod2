Why prices and ratings are withheld

Two Program Policy rules we verified in the fetched text:

  • Prices may be shown only if Amazon serves them within the link, or if obtained via Creators API / PA API with an adjacent date/time stamp and the prescribed disclaimer. This site did neither — so price cells read withheld and are flagged as FLG-P04.
  • Star ratings and review counts may be displayed only when obtained through Creators API / PA API with a link to the review. This site did neither — flagged as FLG-P05.

The practical effect: every price and rating you see is on Amazon's own page, current at the moment you click, and we never restate a stale copy. The owner's options for changing this are on suggestions S-02.

Sources: S-02 · Program Policies (fetched 19 Nov 2026) · S-01 · Operating Agreement (updated 15 Oct 2025).
