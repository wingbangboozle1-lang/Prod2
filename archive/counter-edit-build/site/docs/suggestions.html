Three paths, one choice

Path A — Depth first (recommended default)

Verify spec sheets (SG-01), fill S-23, extend structured data (SG-06), keep cadence. Traffic follows the verification angle once Search Console lands. Nothing new ships until F-04 resolves.

Path B — Reach first

Prioritize Search Console + newsletter (SG-04, SG-07) and publish two more guides before filling blanks. Faster top-line growth; leaves visible blanks for another cycle.

Path C — Trust first

Resolve F-02 (SG-05) and D-22 photography before any new content. Slowest; makes every later page unimpeachable.
