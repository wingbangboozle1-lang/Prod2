Implementation: site/assets/js/tce.js. Events queue in localStorage (last 200) and beacon only to a self-hosted endpoint set via window.TCE_ENDPOINT — unset by default, so nothing leaves the browser today. No cookies, no third-party scripts, no identifiers.

Ledger rules

  1. One row per authorized first-party report; the report tool and export date go in provenance.
  2. Rows without provenance are invalid and must be removed.
  3. clicks may be reconciled against E2 aggregates; reported_orders comes only from the Associates console.
  4. No conversion score, ranking or revenue forecast is derived — ever (D-07).

Why the ledger starts empty

Because every number in it must be authorized and provenanced. An empty, well-defined ledger is honest; a seeded one is fiction that later optimization will trust. The first row arrives with the first real report.

Search Console loop (once T-10 lands)

Weekly: export measured queries → log with provenance → compare against the working calendar → next guide topic follows the strongest measured question, recorded in the decision log. Instinct retires.
