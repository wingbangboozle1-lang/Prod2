# Prod2 — integrated affiliate publication

An Amazon-affiliate **publication** built from verified product registers. Tracking ID
`shopnow047c-20`. This repository now contains **two complete build toolchains** from
parallel sessions, integrated without discarding either (see `COORDINATION.md` for the
full log and both session boards):

| | **Prod2 publication** (`docs/`) — deployed | **Countercraft** (`site/`) — preserved |
|---|---|---|
| Generator | `tools/build.py` (from `data/p2-*.json` + `content/`) | `scripts/build_site.py` (from `data/*.json`) |
| Release gate | `tools/checks.py` (8 sections) | `scripts/verify_site.py` |
| Status | **Live site** on GitHub Pages | Fully buildable + verified in CI, not deployed |
| Guides | 5 question guides + buying guide | 8 guides |
| Registers | intent records, flags (open/resolved/standing), questions, suggestions, decisions, five-event ledger | research desk, suggestions, ledger, articles |
| Links | `rel="sponsored"`, **tagged** `?tag=shopnow047c-20`, enforced | `rel="sponsored"` (tag fix applied at integration) |

## Quick start (clean checkout, standard-library Python)

```bash
python3 tools/build.py && python3 tools/checks.py        # deployed publication
python3 scripts/build_site.py && python3 scripts/verify_site.py   # preserved build
```

## Layout

```
data/p2-*.json   registers for the deployed publication (products, intent, sources,
                 flags, questions, suggestions, decisions, ledger, events, settings)
data/*.json      registers for the Countercraft build (its own schema)
content/pages/   page content fragments for the deployed publication
assets/          css / js / og-card.png (source for the deployed publication)
tools/           build.py, checks.py, make_og.py
scripts/         build_site.py, verify_site.py (Countercraft)
site/            Countercraft generated output (preserved, reproducible)
docs/            DEPLOYED site (generated by tools/build.py)
analytics-endpoint/  Python self-hosted event counter (deployable)
server.mjs       Node self-hosted event counter (Counter Notes lineage, with tests)
archive/         earlier builds preserved (counter-notes-v1, counter-notes-docs)
.github/workflows/  pages.yml (deploys docs/), verify.yml (both gates), analytics-tests.yml
```

## Compliance

- Disclosure strip under the masthead on every page, repeated in the footer.
- Every outbound product link is `rel="sponsored nofollow noopener"`; every `/dp/` product
  link carries `?tag=shopnow047c-20` (enforced by both gates).
- Product-intent records keep intended vs. observed redirect fields separate, never merged.
- Prices and star ratings are not published on the deployed site (F-02); no forecasts anywhere.
